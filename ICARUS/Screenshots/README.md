# ICARUS — реални снимки от българския превод

Тази папка съдържа единствено оригинални екранни снимки, предоставени от автора johnkill34 и показващи действителния превод на български в играта.

Качвайте изображения чрез **Add file → Upload files** в тази папка. Предложени имена: `01-Crafting-BG.png`, `02-Equipment-BG.png`, `03-Items-BG.png`, `04-Gameplay-BG.png`.

Не качвайте изображения от интернет или илюстративни колажи като доказателство за превода.
